**고르지 않은 2개 — 탈락 사유**

| 후보 | 탈락 사유 |
|------|----------|

## ③ 분해 결과 회신 — `③ 완료 후 기입`

③ 워크플로우가 G-1·Q-1의 3,000ms 예산을 단계별로 나눈 결과를 받아 적는 칸임.

기준 워크플로우는 G-1·Q-1이 재는 `W-1 추천 조회`임. 2026-08-11 ③ 완료 후 1회 갱신함.

| 항목 | ③이 회신한 값 |
|------|-------------|
| 단계별 타임아웃 합계 | 2,350ms — 상한만 더한 값(병렬 구간은 최댓값 500ms) |
| 최악값 합계(재시도·폴백 포함) | 2,620ms(p95 합계 1,410ms) |
| 예산 대조 결과(통과·초과) | **통과** — 최악값 2,620ms ≤ 총 시간예산 3,000ms · p95 1,410ms ≤ 응답시간 목표 3,000ms |
| 초과 시 어느 단계를 줄였나 | 초과 없음. 첫 안 3,120ms에서 지도 API 조회 단계의 재시도를 없애고 S-6 추천 캐시 폴백으로 구조를 바꿈. 정상 경로 타임아웃 500ms는 깎지 않음 |
| ③이 되돌려 보낸 `변경요청` | **5건** — ⓐ 화면 3초·API 3초 예산 분리 ⓑ 최악 경로 총량 목표 신설 ⓒ 식사 기록 200ms 기준의 축(p95) 명시 ⓓ 배치·이벤트 워크플로우 목표 신설 ⓔ LLM 폴백 전환 타임아웃을 ③이 1,200ms로 확정해 `V-05` 미확정 10번을 닫음 |

**①이 받아들인 것과 남긴 것** — ⓔ는 ③이 값의 주인이므로 그대로 반영함.
ⓐ는 이 문서의 미확정 항목 1번과 같은 쟁점이라 새 행을 늘리지 않고 그대로 둠.
ⓑⓒⓓ는 성공 기준·품질속성 3개의 축을 바꾸는 제안이라 이번 판에서 자동 반영하지 않고 사용자 판단으로
남김 — G-1·Q-1은 `추천 조회 경로의 p95`를 재는 기준을 유지함.
