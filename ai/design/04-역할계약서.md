# 설계서 ④ 역할계약서 — 런치픽(LunchPick)

**작성**: 플로니(오케스트레이션 엔지니어) · **작성일** 2026-08-11
**입력**: `_shared/프로젝트정보.md`(`V-07`) · `01-목표품질속성카드.md` · `02-논리아키텍처.md` ·
`03-워크플로우설계.md` · 기획 산출물 `docs/plan/`
**미검증 설계** — 실제 권한을 붙여 본 값이 아니라 ②③의 이름과 요구 원문으로 정한 계약임.

이 문서는 **"③의 단계를 몇 명이 나눠 맡고, 그 한 명이 어디까지 손댈 수 있는가"**에 답함.

`R-n`은 담당자 식별자, `S-n`은 내부 저장소, `TB-n`은 Trust Boundary(신뢰 경계), `P-n`은 프로세스이며
`S-n` · `TB-n` · `P-n`은 `02-논리아키텍처.md`가 붙인 번호임. `S-Rn` · `S-Bn` · `S-En`은
`03-워크플로우설계.md`가 붙인 단계 식별자임.

**이 문서가 소유하는 값** — 담당자 수와 묶음 · 저장소·도구의 논리 이름과 권한 등급 · 사람 담당자 배정 ·
승인자 짝짓기 · 사용 모델.
**이 문서가 소유하지 않는 값** — 단계ID · State 필드 이름 · 전달 집합 키 이름 · 타임아웃 · 재시도 ·
모델 호출 횟수(③ 소유, 인용만 함) · 표·열·커넥터 규격·민감 필드 식별자(⑤ 소유, 여기 없음) ·
비용 상한(⑥ 소유).

## 1. 담당자 명부

| `R-n` | 이름 | 종류 | 판정 근거 1줄 |
|-------|------|------|--------------|
| `R-L1` | 추천·설명 문장 생성기 | LLM | ③에서 `1회` 이상인 4단계가 같은 자료(이력·집계·스냅샷)를 보고 같은 출력 검사 규칙을 지므로 한 묶음임 |
| `R-L2` | 취향 임베딩 생성기 | LLM | 문장 생성 묶음과 컨텍스트가 섞이면 문장 규칙과 벡터 규칙을 함께 끌고 다니므로 `Q1`이 `예`임 |
| `R-D1` | 추천 응답 조립 처리기 | Deterministic | 읽기와 되돌릴 수 있는 쓰기만 있고 외부 조회 도구(TB-3·TB-4)를 부르는 유일한 묶음임 |
| `R-D2` | 식사 기록·피드백 처리기 | Deterministic | 외부 서비스 도구 0건이고 `S-3` 이력 저장소 쓰기만 갖는 권한 경계임 |
| `R-D3` | 알림 본문 조립·조건 판정 처리기 | Deterministic | 알림 채널 정보(푸시 토큰 참조·미리보기 본문)를 다루는 유일한 결정론 묶음이라 경계를 뗌 |
| `R-D4` | 취향 벡터 커밋 처리기 | Deterministic | `S-4` 취향 벡터 인덱스에 쓰는 권한을 한 담당자로 모아 직전 1세대 보존 규칙을 한 곳에 둠 |
| `R-D5` | 구독·해지 상태 처리기 | Deterministic | `S-5` 구독·결제 저장소 쓰기 경계이며 되돌릴 수 없는 외부 호출은 갖지 않음 |
| `R-D6` | 온보딩 입력검사·동의 등록 처리기 | Deterministic | `S-1` 회원 저장소 동의·식이제한 쓰기 경계임 |
| `R-D7` | 구독 안내 표시 처리기 | Deterministic | 회원 저장소 쓰기 없이 감사 기록 쓰기와 유예 갱신 호출만 갖는 다른 권한 경계임 |
| `R-D8` | 정기 결제 등록 처리기 | Deterministic | `쓰기(되돌림 불가)`이므로 반드시 따로 뗌 |
| `R-D9` | 알림 발송 호출 처리기 | Deterministic | 되돌릴 수 없는 쓰기가 결제와 다른 종류이므로 둘로 뗌 |
| `R-H1` | 구독·동의 승인자 | Human | ③이 사람 응답을 실시간으로 기다리는 단계 2건과 되돌릴 수 없는 쓰기 2건의 사전 승인을 한 등급으로 묶음 |
| `R-H2` | 실행 중단 담당자 | Human | ③의 `진행 중` 개입 11지점은 저장소 쓰기 0건의 중단 권한이라 재정의 등급과 나눔 |
| `R-H3` | 품질 재정의·감사 담당자 | Human | ③의 `사후` 개입 12지점은 State 재정의 쓰기 권한이며 승인자와 같은 사람을 두면 통제가 성립하지 않음 |

**실행 소유 배정은 LLM·Deterministic 행과 `R-H1`의 실행 소유 2단계로만 셈** — 사람 행의 나머지 항목은
③의 인간 개입 지점을 겹쳐 맡는 자리임(가이드 2-2의 "위 담당자에 더해").

**`담당자 없음`으로 표시한 단말 구간 10단계** — `오늘의 추천 조회 · S-R1` · `S-R14` /
`추천 이유 상세 확인 · S-R21` / `추천 수락·식사 기록·피드백 · S-R31` · `S-R34` · `S-R35` · `S-R39` /
`취향 인사이트 조회 · S-R51` / `구독 결제 · S-R61` / `구독 해지 예약 · S-R81`.
③이 `TB-1` 단말 구간 또는 `TB-8` 단말 구간으로 두고 예산 밖으로 뺀 단계임.
