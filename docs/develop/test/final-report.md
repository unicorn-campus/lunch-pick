## 6. PO/SP 인상 평가 (공통)

### 잘된 점 (Keep)
1. **AI 개인화 체감** — 확신 스코어, "어제 피드백 반영" 배지, 자연어 추천 이유
2. **추천 카드 정보 설계** — 식당명/카테고리/메뉴/거리/매칭률/AI이유를 혼잡함 없이 배치
3. **식사 기록+피드백+취소 통합** — 안전감과 동기부여 공존
4. **온보딩 이탈 방지** — 건너뛰기 + 진행률 바 + 격려 메시지
5. **모바일 퍼스트** — 375px~430px 전 뷰포트에서 가독성/터치 정상
6. **법적 준수** — 위치정보법 고지, 청약철회권, 자동 갱신 동의
7. **데모 모드** — 투자자/이해관계자 데모에 활용 가능

### 아쉬운 점 (Improve)
1. 에러 메시지 일반화 (원인별 구체 안내 부족)
2. 구독 서비스 간 상태 불일치
3. 인사이트 빈 상태 시각적 임팩트 부족
4. 지도 SDK 미연동 (MVP 환경에서 항상 fallback)
