# 핵심 솔루션

**서비스**: 런치픽(LunchPick)
**작성일**: 2026-02-26
**선정 방식**: 9명 투표(B27표+F27표) → 우선순위 매트릭스 → 핵심 솔루션 3개 선정

---

## 선정 결과

### 핵심 솔루션 1: 취향 해자 구독 플라이휠 (A1)

- **선정 근거**: B 득표 7/27로 전체 1위. 9명 중 7명(PO, DE, AR, AI, BE, FE, QA)이 비즈니스 가치를 인정한 압도적 합의. 킹핀 문제(P1)의 근본 원인인 "기억 없는 탐색의 반복"을 식사 데이터 축적이라는 구조적 해자(moat)로 직접 해소한다. Needs Statement의 "쓸수록 나를 더 잘 아는 점심 결정 경험"과 정확히 일치하며, 무료→구독 전환이라는 수익 모델의 핵심이다.
- **비즈니스 가치**: 7/27 (1위)
- **실현 가능성**: 0/27
- **영역**: Bit Bets (전략적 투자)
- **상세 설명**: 무료 사용 시 식사 기억 30일 제한 → 구독 시 무제한 이력 보관. 식사 데이터가 축적될수록 추천 정확도가 상승하고, 축적된 데이터 자체가 이탈 방지 자산(해자)이 된다. "데이터 축적 → 추천 개선 → 만족도 상승 → 기록 동기 → 데이터 축적"의 선순환 플라이휠이 핵심 메커니즘이다. 실현 가능성 득표는 0이므로 단계적 구현 전략이 필요하다.

### 핵심 솔루션 2: 투명한 추천 근거 + 확신 스코어 (A8)

- **선정 근거**: B3+F1로 Bit Bets 영역에서 No Brainers에 가장 가까운 유일한 교차 투표 아이디어. P2(정보 신뢰도 훼손)의 핵심 Pain인 "나를 위한 추천인지 알 수 없다"를 직접 해소한다. 인터뷰 15명 전원이 "아는 사람 추천"을 신뢰 준거점으로 언급했는데, 추천 이유를 자연어로 설명하는 것이 그 경험을 디지털로 재현하는 핵심 장치다.
- **비즈니스 가치**: 3/27 (공동 2위)
- **실현 가능성**: 1/27
- **영역**: Bit Bets → No Brainers 최근접
- **상세 설명**: 추천 결과마다 "왜 이 메뉴인지" 자연어 한 줄 이유 표시 + 상위 3개 추천의 확신 확률 명시 + 추천 근거와 실제 결과의 일치도 감사 추적. 3개 원본 아이디어(8+29+44)가 수렴된 통합 솔루션으로, Explainable AI 기반의 신뢰 형성이 목적이다. 성공 기준 3(신뢰도 4.0/5.0 이상)과 직결된다.

### 핵심 솔루션 3: 원탭 기록 + 빠른 수정 위젯 (A5)

- **선정 근거**: F 득표 3/27로 실현 가능성 공동 1위. 핵심 솔루션 1(취향 해자 플라이휠)이 작동하려면 식사 데이터 축적이 전제 조건이며, 기록 마찰을 최소화하는 이 솔루션이 그 전제를 충족하는 기반 기능이다. 데이터 없이는 해자도, 투명한 근거도 불가능하므로 MVP의 필수 토대가 된다.
- **비즈니스 가치**: 0/27
- **실현 가능성**: 3/27 (공동 1위)
- **영역**: Utilities (기반 기능)
- **상세 설명**: "먹었어요" 1탭 기록 + 홈 위젯 빠른 접근 + 30초 실행 취소. 3개 원본 아이디어(5+40+46)가 수렴된 통합 솔루션으로, 기록 마찰 최소화가 목적이다. 성공 기준 2(쓸수록 나아진다는 체감)의 물리적 기반이며, 기록 데이터가 A1(플라이휠)과 A8(투명 근거) 모두의 원료가 된다.

## 선정 과정 요약

### 1단계: 투표

9명(PO, SP, DE, AR, AI, BE, FE, QA, DO)이 B(비즈니스 가치) 3표, F(실현 가능성) 3표를 독립 투표했다. 총 B 27표 + F 27표가 38개 수렴 아이디어(18 Big + 14 Little Win + 6 Crazy)에 배분되었다.

### 2단계: 우선순위 매트릭스

4개 영역 분류 결과 **No Brainers 영역이 비어 있는** 양극화 패턴이 확인되었다. Big Idea는 B 득표에, Little Win은 F 득표에 집중되어 아이디어 유형과 투표가 정확히 일치했다. 유일한 교차 투표는 A8(B3+F1)과 A35(B1+F3)뿐이었다.

### 3단계: 핵심 솔루션 선정

No Brainers가 없으므로 가이드 기준에 따라 Bit Bets와 Utilities를 조합하는 하이브리드 전략을 적용했다.

**선정 논리**: 기록(A5) → 축적(A1) → 설명(A8)

1. **A1** (Bit Bets, B7): 킹핀 문제 직접 해결 + 수익 모델 + 압도적 B 득표 1위
2. **A8** (Bit Bets→No Brainers 최근접, B3+F1): 신뢰 경험 핵심 + 유일한 교차 투표
3. **A5** (Utilities, F3): A1·A8의 작동 전제인 데이터 수집 기반 + 실현 가능성 1위

세 솔루션이 결합되면 Needs Statement("쓸수록 나를 더 잘 아는 점심 결정 경험")의 전체 흐름이 완성된다:
- **A5**가 식사 데이터를 마찰 없이 수집하고
- **A1**이 축적된 데이터를 이탈 방지 해자이자 추천 개선의 원료로 전환하며
- **A8**이 추천 근거를 투명하게 설명하여 "아는 사람 추천" 수준의 신뢰를 형성한다
