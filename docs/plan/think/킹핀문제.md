## 2. 문제 간 인과관계

```
[P2: 정보 신뢰도 훼손 — 선행 원인]
  "나를 위한 추천인지 알 수 없다"
  추천 이유(Explainability) 부재 + 광고·협찬 혼재
  → 플랫폼 추천 불신 → "아는 사람 추천"에만 의존
          |
          | (선행 원인으로 작용)
          ↓
[P1: 탐색-결정 단절] ←————————————→ [P3: 피드백 루프 단절]
  "기억 없는 탐색의 반복"                "두 가지 기억의 부재"
  어제 먹은 것 모름                       과거 취향 누적 없음
  → 동일 선택지 반복                   + 오늘 컨텍스트 반영 없음
  → 결정 피로                            → 추천이 나아지지 않음
  → 단골 회귀                            → 피드백 동기 소멸
          |                                      |
          |←————— 단일 순환 구조 ————————→|
          ↓
[P2로 복귀 — 악순환 완성]
  개선 없는 추천 → "광고가 아닌가" 의심 강화 → 신뢰 공백 지속
```

**인과관계 상세 설명**:

P2(정보 신뢰도 훼손)는 P1(탐색-결정 단절)의 구조적 선행 원인이다. 사용자가 플랫폼을 신뢰하지 못하면 탐색 자체의 가치를 낮게 평가하게 되고, 결과적으로 탐색에 투자한 시간이 결정 품질을 높이지 못하는 구조가 고착된다.

P1(탐색-결정 단절)과 P3(피드백 루프 단절)은 독립된 두 문제가 아니라 하나의 악순환 구조의 두 진입점이다. "기억 없는 탐색 → 반복 탐색 → 결정 실패 → 피드백 포기 → 기억 없는 탐색"의 사이클이 매일 재생산된다. 문제가설.md 피봇 v1에서 이 구조가 인터뷰 15명을 통해 반복 확인되었다.

P1과 P3의 악순환이 완성되면 "개선 없는 추천 경험"이 P2(광고 의심 강화)를 재강화하는 방향으로 피드백된다. 세 문제는 닫힌 루프를 형성한다.

**킹핀 타격 시 연쇄 해소 구조**: P1과 P3의 순환 구조를 동시에 끊는 것이 P2(신뢰 훼손)의 해소 조건이 된다. 식사 이력 기억 + 이중 인풋 구조(취향 누적 + 실시간 컨텍스트) + 추천 이유 투명성이 세 문제를 동시에 타격하는 단일 설계 방향이다.

## 3. 5가지 기준 평가

### 평가 기준 (각 5점 만점)
- **영향력**: 해결 시 다른 문제도 함께 해결되는가?
- **빈도**: 고객이 얼마나 자주 겪는가?
- **심각도**: 고객에게 미치는 고통의 정도는?
- **근본성**: 다른 문제들의 원인이 되는가?
- **해결가능성**: 현실적으로 해결 가능한가?

| 문제 ID | 영향력 | 빈도 | 심각도 | 근본성 | 해결가능성 | 총점 |
|---------|--------|------|--------|--------|------------|------|
| P1 | 5/5 | 5/5 | 5/5 | 4/5 | 5/5 | **24/25** |
| P2 | 3/5 | 5/5 | 4/5 | 3/5 | 4/5 | **19/25** |
| P3 | 4/5 | 5/5 | 4/5 | 5/5 | 4/5 | **22/25** |

### 점수 근거 상세

**P1: 탐색-결정 단절 (총점 24/25)**

- **영향력 5/5**: P1이 해결되면 P3(피드백 루프 단절)가 연쇄 해소된다. 문제가설.md에서 "P1과 P3는 단일 순환 구조의 두 진입점"으로 명시. 추가로 P2(신뢰 훼손)의 체감 강도도 낮아진다. 세 문제 중 가장 넓은 연쇄 해결 범위.
- **빈도 5/5**: 점심이라는 일일 반복 행위와 직결. 수도권 오피스 근무 직장인 기준 연간 약 250회 발생. 모든 세그먼트에서 빠짐없이 경험.
- **심각도 5/5**: 핵심 타깃 8명 기준 중요도 4.50/5.0, 불편도 4.38/5.0으로 세 문제 중 Pain 강도 최고. 탐색 13~18분 소비 + 결과 없는 단골 회귀라는 이중 손실 구조. 장기적으로 탐색 포기 및 무기력감 고착으로 심화됨(황소연, 황미영 사례).
- **근본성 4/5**: P1은 P3와 상호 원인이므로 완전한 일방향 근본 원인은 아님. P2(신뢰 훼손)는 P1의 선행 원인이므로 P1이 모든 문제의 근본은 아님. 그러나 P1 해결이 P3 해소에 가장 직접적으로 연결됨.
- **해결가능성 5/5**: "식사 이력 자동 기록 + 3~5개 제한 추천"으로 즉각 해결 가능한 UX 설계 포인트. 기술적 난이도가 P3(이중 인풋 ML 파이프라인)보다 낮음. 인터뷰에서 "어제 먹은 것 기억/중복 제외" 요청 5명, "3~5개로 제한된 추천" 요청 6명 — 해결 방향이 구체적으로 검증됨.

**P2: 광고 기반 정보 왜곡 (총점 19/25)**

- **영향력 3/5**: P2 단독 해결로 P1·P3가 연쇄 해소되지 않는다. P1·P3를 해결하면 P2의 체감 강도가 줄어드는 방향이지, 역방향 인과는 약하다.
- **빈도 5/5**: 플랫폼을 탐색할 때마다 광고 노출 발생. 탐색 행위와 동기화되어 매일 발생.
- **심각도 4/5**: 불편도 평균 3.53으로 세 문제 중 최고이나, 핵심 타깃 기준 Pain 강도(4.25)는 P1(4.38)보다 낮음. 근본원인 표현("광고 구조")에 대한 강한 동의는 27%(4명)에 그침 — 황소연 "음모론처럼 들린다" 언급. 현상 인정은 강하나 원인 공감도는 낮음.
- **근본성 3/5**: P2는 P1의 선행 원인이지만, P1·P3의 악순환이 P2를 재강화하는 구조이므로 완전한 선행 원인이 아닌 상호 순환 관계. P2 단독 해결이 시스템 전체를 바꾸지 않음.
- **해결가능성 4/5**: "추천 이유 투명성(Explainable AI)"이 해결 방향으로 검증됨. 그러나 "광고 없음" 선언만으로는 불충분하고 추천 품질이 실제로 나아져야 신뢰가 형성되므로, P1·P3 해결에 의존하는 부분이 있음.

**P3: 피드백 루프 단절 (총점 22/25)**

- **영향력 4/5**: P3 해결 시 P1(기억 없는 탐색)이 연쇄 해소되고, P2(추천 불신)의 체감 강도도 감소. P1과 단일 순환 구조이므로 P3 해결 = P1 동시 해결에 근접하나, P3 단독 진입점으로서 UX가 P1보다 복잡함.
- **빈도 5/5**: 식사 후 피드백 기회가 매일 발생하나 매번 소실. 탐색 행위와 동일 빈도.
- **심각도 4/5**: 중요도 평균 3.87로 세 문제 중 최고이나, 불편도는 3.47로 P2(3.53), P1(3.47)과 동일 수준. 장기 악순환 고착의 근본 원인이나 즉각적 Pain보다 만성적 Pain에 가까움.
- **근본성 5/5**: P3가 해결되면 "기억 없는 탐색" 메커니즘(P1의 핵심 원인)이 직접 제거됨. 세 문제의 악순환 구조에서 가장 근본에 위치. 강하게 동의 47%(7명)으로 세 문제 중 최고 — 사용자들이 이 문제를 가장 본질로 인식.
- **해결가능성 4/5**: 이중 인풋 구조(취향 누적 + 실시간 컨텍스트) 설계가 필요하여 P1보다 기술 복잡도 높음. 초간단 피드백 UX(이모지·3택) 요청 7명, 즉각 반영 확인 요청 6명 — 해결 방향 구체적으로 검증되었으나 ML 파이프라인 구현 난이도 존재.

## 4. 킹핀 문제 선정

- **킹핀 문제**: **P1 — 탐색-결정 단절 ("기억 없는 탐색의 반복")**

- **선정 근거**:
  1. **총점 최고 (24/25)**: 5가지 평가 기준 중 영향력·빈도·심각도·해결가능성 4개에서 만점(5/5). P3(22/25), P2(19/25) 대비 명확한 격차.
  2. **진입점으로서의 최우선성**: 핵심 타깃 8명 기준 Pain 강도 중요도 4.50/5.0, 불편도 4.38/5.0으로 세 문제 중 최고. 사용자가 "지금 당장 해결되기를 원하는" 즉각적 Pain이며 매일 발생하는 일상 행위와 직결됨.
  3. **인과관계 중심성**: P1이 해결되면 P1↔P3의 악순환 구조가 끊기고, P2의 체감 강도도 감소하는 연쇄 효과 발생. P1은 세 문제의 교차점에 위치한 병목이다.
  4. **해결 가능성의 현실성**: "식사 이력 기록 + 중복 제외 + 3~5개 추천"이라는 구체적 UX 설계로 MVP 단계에서 즉각 구현 가능. P3(ML 이중 인풋 파이프라인) 대비 기술 난이도 낮고 초기 검증 속도가 빠름.
  5. **비즈니스 가치 연결**: 비즈니스가치.md 고객 가치 1("매일 낭비되는 점심 결정 시간의 회복")과 직접 연결됨. "앱 진입 후 메뉴 결정 5분 이내"라는 측정 가능한 목표가 이미 수립되어 있음.

- **연쇄 해결 예상 문제**:
  - P3(피드백 루프 단절): P1 해결 솔루션(식사 이력 자동 기록)이 P3의 근본 원인인 "과거 취향 누적 부재"를 동시에 해소함. P1↔P3 순환 구조가 한 번에 끊김.
  - P2(정보 신뢰도 훼손): P1 해결 과정에서 "추천 이유 투명성(Explainable AI)"을 설계하면 P2의 핵심 Pain("나를 위한 추천인지 알 수 없다")이 함께 해소됨.
  - 비즈니스가치.md의 "데이터 기반 Lock-in(회사 가치 2)"도 P1 해결(식사 이력 누적)을 기반으로 자연스럽게 형성됨.
