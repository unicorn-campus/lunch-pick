## 1. Lean Canvas

### Problem (문제)

- **P1: 탐색이 결정으로 이어지지 않는다** — 직장인은 점심 메뉴를 고르기 위해 평균 13~18분을 탐색하지만, "기억 없는 탐색의 반복" 메커니즘으로 기존 단골로 회귀한다. 핵심 타깃 중요도 4.50/5.0, 불편도 4.38/5.0.
- **P3: 식사 경험이 다음 선택에 반영되지 않는다** — 과거 취향 누적(장기 메모리)과 오늘의 컨텍스트 인식(단기 입력) 두 가지 기억이 모두 부재하여 "쓸수록 나아지는 서비스"가 존재하지 않는다. 중요도 3.87/5.0(세 문제 중 최고), 강하게 동의 47%.
- **P2: 추천을 신뢰할 수 없다** — "나를 위한 추천인지 알 수 없다"는 설명 부재가 핵심. 15명 전원이 "아는 사람 추천"을 신뢰 준거점으로 언급. 불편도 3.53/5.0(세 문제 중 최고).
- **현재 대안**: 카카오맵·네이버지도(탐색 도구, 개인화 학습 없음), 배달앱(주문 도구, 결정 지원 없음), 동료 추천(확장 불가), SNS 맛집 콘텐츠(위치·맥락 연결 없음). 어떤 대안도 "기억 + 맥락 + 설명"을 결합하지 못함.

### Customer Segments (고객 세그먼트)

- **Primary Target**: 수도권 오피스 근무 25~35세 직장인 중 매일 점심 메뉴 결정을 스스로 내려야 하는 혼밥 또는 소규모 그룹(세그먼트 1: 결정 피로 직장인). 수도권 오피스 외식 직장인 추정 350만 명.
- **Early Adopters**: 강남·여의도·판교 IT·금융 직장인. 디지털 서비스 수용도 높음, 점심 예산 1만~1.5만 원, AI 추천 서비스에 호의적. 블라인드·직장인 커뮤니티 활동 활발.
- **Customer Jobs**: "나는 점심시간마다 내 취향과 상황에 맞는 최적의 식사를 최소한의 시간과 에너지로 결정하고 싶다." Functional(5분 이내 결정) + Emotional(후회 없는 선택) + Social(팀 갈등 없는 합의).

### Unique Value Proposition (고유 가치 제안)

- **핵심 가치**: "쓸수록 나를 더 잘 아는 점심 결정 파트너 — 어제의 기억과 오늘의 상황으로 이유 있는 추천 3개를 3분 안에."
- **High-level Concept**: "점심 결정을 위한 Spotify" — Spotify가 음악 취향을 학습하여 개인화 플레이리스트를 제공하듯, 런치픽은 식사 취향을 학습하여 개인화 점심 추천을 제공한다. 들을수록 나를 아는 음악 추천처럼, 쓸수록 나를 아는 점심 추천.

### Solution (솔루션)

핵심 솔루션 3개가 "기록 → 축적 → 설명"의 플라이휠을 형성한다.

- **A5: 원탭 기록 + 빠른 수정 위젯** (P1·P3 해결 기반): "먹었어요" 1탭으로 식사 기록. 홈 위젯 빠른 접근 + 30초 실행 취소. 기록 마찰을 최소화하여 데이터 축적의 물리적 토대를 만든다. F 득표 3/27(공동 1위).
- **A1: 취향 해자 구독 플라이휠** (P1·P3 직접 해결): 축적된 식사 데이터가 추천 정확도를 향상시키고, 데이터 자체가 이탈 방지 해자가 되는 선순환 구조. 무료 30일 기억 제한 → 구독 시 무제한 이력. B 득표 7/27(압도적 1위).
- **A8: 투명한 추천 근거 + 확신 스코어** (P2 직접 해결): 추천마다 "왜 이 메뉴인지" 자연어 한 줄 이유 + 상위 3개 확신 확률 명시. Explainable AI로 "아는 사람 추천" 수준의 신뢰 형성. B 득표 3/27 + F 득표 1/27(No Brainers 최근접).

### Channels (채널)

- **Acquisition (고객 획득)**:
  - 블라인드·점심 메뉴 관련 직장인 커뮤니티 바이럴
  - "오늘 점심 뭐 먹었어?" 인스타그램·틱톡 숏폼 콘텐츠 마케팅
  - 강남·여의도·판교 오피스 건물 인근 QR 마케팅 (11시 점심 직전 트래픽 공략)
  - 앱스토어 ASO(App Store Optimization) — "점심 추천", "메뉴 결정" 키워드
- **Delivery (제품 전달)**:
  - iOS/Android 네이티브 앱 (홈 위젯 포함)
  - 점심 30분 전 푸시 알림 (오늘의 추천 3개)
  - 카카오톡 알림톡 연동 (선택적)
- **Retention (고객 유지)**:
  - 취향 데이터 축적에 따른 추천 품질 자동 향상 (A1 플라이휠)
  - 주간 취향 인사이트 리포트 ("이번 주 당신의 점심 패턴")
  - 식사 이력 타임라인 시각화 (데이터 가치 체감)

### Unfair Advantage (경쟁우위)

**"쓸수록 깊어지는 개인 취향 데이터 해자(Data Moat)"**

1. **데이터 플라이휠**: 사용할수록 식사 이력·취향·피드백이 축적되어 추천 정확도가 상승하고, 정확도 상승이 사용 빈도를 높이는 자기 강화 구조. 경쟁사가 서비스를 복제해도 개별 사용자의 축적된 취향 데이터는 복제 불가.
2. **전환 비용**: 90일 이상 사용자는 50건 이상의 식사 이력과 정교한 취향 프로파일을 보유하게 되어, 다른 서비스로 전환 시 "처음부터 다시 학습시키는" 비용이 발생한다. 오채연 인터뷰: "6년 다니면서 쌓인 맛집 정보가 팀 바뀌고 나서 다 사라졌거든요" — 데이터 소실에 대한 상실감이 Lock-in 효과의 실증.
3. **점심 결정 특화 포지션**: "탐색이 아닌 결정"이라는 포지션은 현재 시장에서 공백. 배달앱(주문), 맛집앱(탐색), 지도앱(위치)과 모두 다른 카테고리. 점심 특화 버티컬의 깊이는 범용 빅테크 앱이 단기간에 복제하기 어려움.

| **팀** | 인당 3,000원/월 (연 2,500원/월, 최소 5인) | 팀원 취향 통합, 팀 추천, HR 대시보드 | 2단계 (개인 Lock-in 형성 후) |

### 가격 책정 근거

- **심리적 앵커링**: 점심 1끼 평균 12,000원 대비 월 4,900원은 "0.4끼 값". "한 달 내내 후회 없는 점심을 0.4끼 값에" 메시지.
- **30일 기억 제한**: 무료 사용자가 30일간 축적한 취향 데이터가 사라지는 시점에서 전환 동기가 자연 발생. 강제 차단이 아닌 "기억 유지" 가치 제안.
- **연 결제 할인**: 월 4,900원 → 연 46,800원(월 3,900원). 20% 할인으로 연 결제 유도, LTV 안정화.

### Unit Economics

| 항목 | 수치 | 비고 |
|------|------|------|
| LTV | 55,000원 | ARPU 4,400원 × 12.5개월 |
| CAC | 15,000원 (1년차) → 8,000원 (3년차) | 바이럴 계수 상승에 따른 CAC 하락 |
| LTV/CAC | 3.7x (1년차) → 6.9x (3년차) | 건전 기준 3x 이상 충족 |
| 회수 기간 | 3.4개월 (1년차) → 1.8개월 (3년차) | CAC ÷ 월 ARPU |

## 4. Key Metrics 상세

### AARRR 퍼널 설계

**Acquisition (획득)**
- **핵심 지표**: CAC, 월간 신규 가입자, 채널별 전환율
- **측정 방법**: UTM 파라미터 + 앱스토어 어트리뷰션
- **목표**: 1년차 누적 가입 30,000명, CAC 15,000원 이하
- **경고 임계치**: CAC > LTV/3 (18,300원) 시 채널 전략 재검토

**Activation (활성화)**
- **핵심 지표**: 가입→첫 추천 수락률, 온보딩 퀴즈 완료율, "Aha Moment" 도달률
- **Aha Moment 정의**: "첫 추천 수락 후 만족 반응(좋았어요) 1회" — 이 경험을 한 사용자의 30일 리텐션이 2배 이상 높을 것으로 가설 설정
- **목표**: 온보딩 완료율 70%, 첫 추천 수락률 40%

**Retention (유지)**
- **핵심 지표**: D1/D7/D30 리텐션, 월간 Churn Rate, WAU/MAU 비율
- **측정 방법**: 코호트 분석 (주간 가입 코호트별 리텐션 추적)
- **목표**: D30 리텐션 30% (1년차) → 45% (3년차)
- **경고 임계치**: D7 리텐션 < 40% 시 온보딩 플로우 개선 필요

**Revenue (수익)**
- **핵심 지표**: MRR, ARPU, 구독 전환율, 구독 유지율
- **무료→유료 전환 트리거**: 30일 기억 제한 도달 시점의 전환율 집중 측정
- **목표**: 구독 전환율 5% (1년차) → 10% (3년차), 월 Churn 15% → 8%

**Referral (추천)**
- **핵심 지표**: K-factor(바이럴 계수), NPS, "공유하고 싶다" 응답률
- **바이럴 메커니즘**: "오늘 런치픽이 추천한 메뉴" 카카오톡 공유, 팀 초대 보상
- **목표**: K-factor 0.3 (1년차) → 0.8 (3년차)

### 비즈니스가치.md 연계 지표

| 비즈니스 가치 | 연계 AARRR 지표 | 목표 |
|-------------|---------------|------|
| 고객 1: 결정 시간 회복 | Activation — 결정 소요시간, 재탐색 0회 비율 | 5분 이내, 60% |
| 고객 2: 쓸수록 나아지는 개인화 | Retention — 주차별 만족도, 누적 피드백 횟수 | 4주차 +0.5점, 월 20회 |
| 고객 3: 아는 사람 추천 신뢰감 | Referral — 추천 신뢰도, NPS | 4.0/5.0, NPS 30+ |
| 회사 1: 구독 수익 모델 검증 | Revenue — 전환율, MRR, Churn | 전환율 5%, Churn 15% |
| 회사 2: 데이터 Lock-in | Retention — 60일+ 사용자 이탈율, 누적 이력 건수 | 이탈율 5%, 50건+ |
| 회사 3: B2B 수익화 경로 | Revenue — 팀 모드 대기자, 팀 전환율 | 대기자 500명, 전환 20% |

## 6. Go-to-Market 전략

### Pre-launch (론칭 전, M1~M4)

- **클로즈드 베타 100명 모집**: 강남·여의도·판교 IT 직장인 대상. 블라인드 게시글 + 직장인 슬랙 커뮤니티.
- **핵심 검증 지표**: 추천 만족도 4.0/5.0 이상, 결정 시간 5분 이내 비율 50% 이상.
- **법적 기반 구축**: 위치기반서비스 사업 신고, 개인정보처리방침 수립, 통신판매업 신고.
- **콘텐츠 씨앗 뿌리기**: "점심 결정 피로" 공감 콘텐츠 인스타·틱톡 10편 사전 제작.

### Launch (론칭, M5~M6)

- **오픈 베타 → 정식 출시**: DAU 500명 목표. 초기 앰배서더 50명 모집 (무료 프리미엄 3개월 제공).
- **바이럴 매커니즘 가동**: "오늘 런치픽이 추천한 메뉴" 카카오톡 공유 카드. 공유 시 추천인·피추천인 모두 프리미엄 7일 무료.
- **오피스 지역 거점 공략**: 강남역·여의도역·판교역 반경 500m 오피스 QR 마케팅. 점심 직전(11:00~11:30) 시간대 집중.
- **PR**: "점심 결정에 하루 18분 낭비" 데이터 기반 보도자료. 스타트업 미디어(플래텀·벤처스퀘어) 게재.

### Post-launch (론칭 후, M7~M12)

- **성장 가속**: DAU 1,000명 → MAU 10,000명 목표. 디지털 퍼포먼스 마케팅(구글·메타 앱 설치 캠페인).
- **리텐션 강화**: 30일 기억 제한 도달 사용자 대상 전환 넛지. 주간 취향 인사이트 리포트로 데이터 가치 체감 극대화.
- **B2B 파일럿**: 기업 HR 담당자 3~5개사 파일럿 계약. 팀 모드 베타 테스트. 식권 연동 PoC.
- **구독 수익 검증**: 전환율 5% 달성 여부로 구독 모델 검증. 미달 시 가격·기능·전환 시점 A/B 테스트.
