## 유저플로우-여정 단계 매핑

| 유저플로우 | 고객 여정 단계 | 감정 레벨 | UX 보완 설계 |
|-----------|-------------|----------|-------------|
| 01. 회원가입 및 온보딩 | (진입 전) | — | 3분 완료 안내, 진행률 표시, 최소 7장 스와이프로 유연화 |
| 02. 오늘의 추천 조회 | 1. 배고픔 인식 (2) → 2. 메뉴 탐색 (1) | **1~2** | **최우선 보완**: 추천 이유 한 줄 즉시 표시, 콜드스타트 안전망 자동 적용, "아직 학습 중" 투명 안내 |
| 03. 추천 수락 및 식당 선택 | 2. 메뉴 탐색 (1) → 3. 선택 결정 (2) | **1~2** | **최우선 보완**: 거절 시 대체 추천 즉시 제시, 확신 스코어로 결정 불안 해소, 전체 새로고침 경로 제공 |
| 04. 식사 기록 | 5. 식사 평가 (2) | **2** | 10초 피드백 UX, 리마인더 1회만 (강제 없음), 30초 실행 취소, "내일 반영" 메시지로 동기 부여 |
| 05. 취향 학습 및 프로파일 갱신 | 6. 루틴 형성 (2) | **2** | "어제 피드백 반영" 가시화 태그, 피드백 부족 시 격려 메시지, 추천 정확도 향상률 표시 |
| 06. 취향 인사이트 조회 | 6. 루틴 형성 (2) | **2** | 30끼 마일스톤 축하, 주간 패턴 인사이트, 무료 제한 시 부드러운 프리미엄 안내 |
| 07. 구독 전환 | 6. 루틴 형성 (2) | **2** | 강제 차단 아닌 가치 제안 ("데이터가 사라져요"), 7일 무료 체험 제공, 결제 실패 시 7일 유예 |

**감정 레벨 2 이하 대응 요약**: 7개 유저플로우 중 6개(02~07)가 감정 레벨 2 이하 단계를 지원한다. 모든 유저플로우에 에러 처리 강화(친절한 안내), 피드백 이벤트(진행 상태 전달), 안내 메시지(도움말), 복구 경로(이전 단계 복귀)를 설계에 반영했다.

## 마이크로서비스 정의

### 이벤트 클러스터링 → Aggregate → 바운디드 컨텍스트

| 이벤트 클러스터 | 주요 이벤트 | Aggregate | 바운디드 컨텍스트 |
|--------------|-----------|-----------|----------------|
| 인증/프로파일 | 회원가입 완료됨, 로그인 완료됨, 온보딩 완료됨, 식이제한 설정 완료됨, 구독 상태 갱신됨 | 회원(Member), 취향프로파일(PreferenceProfile) | **회원 컨텍스트** |
| 추천 생성 | 오늘의 추천 제시됨, 안전망 추천 제시됨, 취향 임베딩 갱신됨, 학습 반영 메시지 생성됨 | 추천(Recommendation), 취향벡터(PreferenceVector) | **추천 컨텍스트** |
| 식사 이력/피드백 | 식사 기록 완료됨, 식사 기록 수정됨, 피드백 저장 완료됨, 식사 이력 타임라인 표시됨 | 식사기록(MealRecord), 피드백(Feedback) | **이력 컨텍스트** |
| 결제/구독 | 구독 결제 완료됨, 정기 결제 등록 완료됨, 결제 실패됨, 프리미엄 활성화 완료됨 | 구독(Subscription), 결제(Payment) | **결제 컨텍스트** |

### 분할/병합 결정

| 바운디드 컨텍스트 | 분할 기준 해당 여부 | MVP 결정 |
|----------------|------------------|---------|
| 회원 컨텍스트 | 변경 빈도 낮음, 데이터 소유 독립 | **독립 유지** — 인증/프로파일은 안정적 |
| 추천 컨텍스트 | **차별화 핵심** + **부하 변동** (피크타임 12~13시) + **변경 빈도** (AI 모델 교체) | **독립 유지** — 핵심 경쟁력, 독립 스케일링 필요 |
| 이력 컨텍스트 | 데이터 소유 독립, 쓰기 빈도 높음 | **MVP에서 추천과 병합** → 트래픽 증가 시 분리 |
| 결제 컨텍스트 | 트랜잭션 경계 독립, 외부 시스템 의존 | **독립 유지** — PG 연동 격리 필요 |

### MVP 마이크로서비스 구성

| 서비스명 | 바운디드 컨텍스트 | 관련 유저플로우 | 주요 이벤트 | 외부 시스템 |
|---------|----------------|-------------|-----------|-----------|
| **회원 서비스** | 회원 컨텍스트 | 01, 07 | 회원가입 완료됨, 온보딩 완료됨, 식이제한 설정 완료됨, 구독 상태 갱신됨 | (E)카카오 로그인 |
| **추천·이력 서비스** | 추천 컨텍스트 + 이력 컨텍스트 (MVP 병합) | 02, 03, 04, 05, 06 | 추천 제시됨, 식사 기록 완료됨, 피드백 저장됨, 취향 임베딩 갱신됨, 인사이트 표시됨 | (E)LLM API, (E)지도 API, (E)날씨 API |
| **결제 서비스** | 결제 컨텍스트 | 07 | 구독 결제 완료됨, 정기 결제 등록 완료됨, 결제 실패됨 | (E)결제 게이트웨이 |

### 컨텍스트 맵

```
[회원 서비스] ──(동기 호출)──> [추천·이력 서비스]
     │                              │
     │ (취향 프로파일 조회)           │ (구독 상태 확인)
     │                              │
     └──(동기 호출)──> [결제 서비스] <─┘
                         │
                    (E)결제 게이트웨이
```

- **회원 → 추천·이력**: 취향 프로파일 데이터 전달 (동기)
- **추천·이력 → 회원**: 구독 상태 확인 (동기, 이력 조회 기간 제한용)
- **회원 → 결제**: 구독 전환 요청 (동기)
- **결제 → 회원**: 구독 상태 갱신 이벤트 (비동기)
