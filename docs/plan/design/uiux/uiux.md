## 1. 디자인 원칙

### 핵심 원칙 (5개)

1. **3초 결정 (Instant Decision)**: 앱을 열면 스크롤 없이 한 화면에서 오늘의 추천 3개를 즉시 확인한다. 탐색 13~18분을 30초 이내로 단축하는 것이 모든 화면 설계의 최우선 기준이다.
2. **투명한 이유 (Transparent Why)**: 모든 추천에는 "왜 이 메뉴인지" 자연어 한 줄 이유와 확신 스코어를 표시한다. 광고가 아닌 "내 취향 기반"임을 시각적으로 증명한다.
3. **원탭 기록 (One-Tap Record)**: 식사 기록은 1탭·1초, 피드백은 10초 이내에 완료된다. 입력 마찰을 제거하여 데이터 축적 플라이휠의 토대를 만든다.
4. **감정 케어 (Emotion Care)**: 여정맵 감정 레벨 2 이하 구간(탐색·결정·평가·루틴)의 화면에는 진행 안내, 에러 복구, 격려 메시지, 도움말을 필수 포함한다.
5. **점진적 가치 체감 (Progressive Value)**: 데이터가 쌓일수록 추천이 나아지고, 그 변화를 "어제 피드백 반영" 태그, 마일스톤 축하, 인사이트 리포트로 사용자가 직접 체감하게 한다.

### 디자인 언어

- **톤 앤 매너**: 친근하고 따뜻한 조언자. 강요하지 않고 제안하며, 실패해도 다시 시도할 수 있는 안전한 느낌.
- **브랜드 키워드**: 신뢰, 간결, 따뜻함

## 3. 사용자 플로우

### 플로우 1: 신규 가입 및 온보딩 (Epic 1)

```
시작 (앱 최초 실행)
 ↓
[스플래시] → [로그인 화면]
                ↓ (카카오 로그인)
            [취향 퀴즈] ← 진행률 표시, 최소 7장
                ↓ (스와이프 완료)
            [위치 동의] ← 수집 목적·보유기간 고지
                ↓ (동의/거절)
            [식이제한 설정] ← 선택사항, 스킵 가능
                ↓
            [홈 (첫 추천)]
```

**플로우 설명**:
1. **스플래시**: 브랜드 로고 + "3분이면 당신만의 점심 파트너가 완성돼요" 안내
2. **로그인 화면**: 카카오 로그인 단일 버튼. 간결한 가치 제안 한 줄
3. **취향 퀴즈**: 음식 카드 스와이프(좋아요/싫어요). 진행률 바 표시. 최소 7장 완료 시 "완료" 버튼 활성화
4. **위치 동의**: 위치정보법 준수 고지 + 동의/거절 버튼. 거절 시 수동 입력 모드 안내
5. **식이제한 설정**: 알레르기 8대 알레르겐 체크 + 식이 유형 선택. "나중에 하기" 허용
6. **홈 (첫 추천)**: 온보딩 완료 축하 + 첫 추천 3개 표시

### 플로우 2: 추천 → 결정 → 기록 (핵심 루프, Epic 2-4)

```
[홈: 추천 3개 표시]
 ↓                    ↓                     ↓
[카드 탭: 이유 상세]  [수락: "여기 갈래요"]  [거절: 왼쪽 스와이프]
                      ↓                     ↓
                  [길찾기 안내]          [거절 사유 선택]
                      ↓                     ↓
                  (식사 실행)            [대체 추천 1개 표시]
                      ↓
                  [원탭 기록: "먹었어요"]
                      ↓
                  [간단 피드백: 좋아요/별로 + 키워드]
                      ↓
                  ["내일 추천에 반영할게요" 완료]
```

**플로우 설명**:
1. **홈**: 추천 3개 카드 형태. 각 카드에 식당명, 대표 메뉴, 추천 이유 한 줄, 확신 스코어, 거리
2. **이유 상세**: "왜?" 버튼 탭 → 바텀시트로 자연어 설명 + 컨텍스트 태그 표시
3. **수락**: "여기 갈래요" 탭 → 길찾기 화면(도보 경로 + 예상 소요시간 + 외부 지도앱 연동)
4. **거절**: 왼쪽 스와이프 → 거절 사유 4지선다 → 대체 추천 1개 즉시 표시
5. **원탭 기록**: 식사 시간 경과 후 알림 또는 홈 화면에서 "먹었어요" 1탭
6. **간단 피드백**: 좋아요/별로(필수) + 맛/양/속도 키워드(선택) → 10초 완료

### 플로우 3: 인사이트 조회 (Epic 6)

```
[하단 탭: 인사이트]
 ↓
[이력 타임라인: 30일 달력 뷰]
 ↓ (인사이트 탭)
[취향 리포트: 카테고리 Top 5 + 주간 패턴 + 만족도 그래프]
 ↓ (30끼 달성 시)
[마일스톤 축하: "추천 정확도 42% 올랐어요"]
```

### 플로우 4: 구독 전환 (Epic 7)

```
[기억 제한 도달 안내] 또는 [프로필 > 구독]
 ↓
[플랜 비교: 무료 vs 프리미엄]
 ↓ (구독 선택)
[결제 수단 등록]
 ↓ (결제 완료)
[프리미엄 활성화 완료]
```

**핵심 요소**:
- **추천 카드**: 식당명, 대표 메뉴, 가격, 확신 스코어(%), 도보 시간, 추천 이유 한 줄. 왼쪽 스와이프로 거절 가능
- **확신 스코어**: 상위 3개의 매칭 확률을 %로 표시. 숫자가 클수록 진한 Primary Color
- **"왜?" 버튼**: 탭 시 바텀시트로 추천 근거 상세 표시 (A8: 투명한 추천 근거)
- **"여기 갈래요" 버튼**: Primary CTA. 탭 시 수락 기록 + 길찾기 화면 전환
- **전체 새로고침**: 3개 모두 마음에 안 들 때 완전히 새로운 추천 요청
- **콜드스타트 배너**: 피드백 5건 미만 시 카드 상단에 "아직 취향을 학습 중이에요. 3일만 더 기록하면 추천이 확 달라져요!" 안내
- **학습 반영 태그**: 전일 피드백 반영 시 "어제 피드백 반영 ✓" 태그 표시

- **중간 이탈 복구**: 진행 상태 자동 저장, 재진입 시 이어서 진행

  - 위치: 화면 상단 풀 와이드

  - 사용: "30끼 기록 달성! 추천 정확도가 42% 올랐어요"

## 7. 접근성 (WCAG 2.1 AA)

### 준수 체크리스트

- [x] 키보드 네비게이션 지원 (Tab, Enter, Space, Arrow keys)
- [x] 스크린 리더 호환 (적절한 HTML 시맨틱 사용)
  - 추천 카드: `role="article"`, `aria-label="추천 1: 미소된장, 확신도 87%"`
  - 스와이프 영역: `aria-roledescription="swipeable"`, 대체 버튼 제공
  - 확신 스코어: `aria-valuenow="87"`, `aria-valuemin="0"`, `aria-valuemax="100"`
- [x] 색상 대비율 >= 4.5:1 (텍스트), >= 3:1 (UI 컴포넌트)
  - Primary Text (#1A1A2E) on Light (#FAFAFA): 대비율 15.3:1
  - Primary Button Text (#FFFFFF) on Primary (#FF6B35): 대비율 4.6:1
- [x] 이미지 대체 텍스트 (alt 속성): 음식 이미지, 차트 이미지 모두 대체 텍스트 포함
- [x] ARIA 레이블 (role, aria-label, aria-describedby): 모든 인터랙티브 요소에 적용
- [x] 폼 레이블 (label 요소): 모든 입력 필드에 연결된 label
- [x] 포커스 인디케이터 (visible focus indicator): 2px Primary Color 아웃라인

### 추가 접근성 고려사항

- **스와이프 대체**: 좋아요/싫어요 버튼, 수락/거절 버튼을 카드 내부에 배치하여 스와이프 불가능 사용자도 동일 기능 사용
- **모션 감소**: `prefers-reduced-motion` 미디어 쿼리 지원. 애니메이션 비활성화 옵션
- **텍스트 크기 조정**: 시스템 글꼴 크기 설정 존중 (rem 단위 사용)
- **터치 타겟**: 모든 인터랙티브 요소 최소 44x44px

## 8. 사용성 테스트

### 테스트 체크리스트

- [ ] **5초 테스트**: 첫인상 평가 — 홈 화면을 5초 본 후 "이 앱이 무엇을 하는 앱인지" 인식률 측정. 목표: 80% 이상 "점심 추천"으로 인식
- [ ] **태스크 완료율**: 주요 태스크 완료 여부
  - T1: 온보딩 완료 (3분 이내): 목표 90%
  - T2: 추천 수락 후 길찾기 확인 (30초 이내): 목표 95%
  - T3: 식사 기록 + 피드백 완료 (15초 이내): 목표 85%
  - T4: 인사이트 리포트 조회 (10초 이내): 목표 90%
- [ ] **에러율**: 사용 중 발생한 에러 빈도 — 목표: 태스크당 평균 에러 0.5회 미만
- [ ] **만족도 점수**: SUS (System Usability Scale) — 목표: 75점 이상 (Good 등급)
- [ ] **NPS (Net Promoter Score)**: 추천 의향 — 목표: +30 이상

### 핵심 태스크 시나리오

| 시나리오 | 시작 | 성공 기준 | 측정 지표 |
|---------|------|----------|----------|
| 첫 사용자 온보딩 | 앱 최초 실행 | 취향 퀴즈 완료 + 첫 추천 확인 | 완료율, 소요시간 |
| 추천 확인 및 수락 | 홈 화면 진입 | 추천 1개 수락 + 길찾기 확인 | 완료율, 수락까지 시간 |
| 식사 후 기록 | 알림 수신 | 원탭 기록 + 피드백 완료 | 완료율, 소요시간, 스킵률 |
| 인사이트 확인 | 하단 탭 인사이트 | 카테고리 분포 + 주간 패턴 확인 | 완료율, 체류시간 |
| 구독 전환 | 기억 제한 도달 안내 | 플랜 비교 확인 + 결제 완료 | 전환율, 이탈 지점 |
