- "제가 어제 뭘 먹었는지를 기억해서 오늘은 부족한 영양소 위주로 추천해주면 정말 좋겠어요."

- "제가 싫어하는 재료(해산물, 고수 같은)는 아예 필터로 영구 제거해줬으면 해요."

## 주요 인사이트

**1. 건강식 카테고리에서 문제 2(정보 신뢰)가 추가 심화됨**

장하윤은 세 문제 중 문제 2에 가장 강하게 반응했다. 일반 식당과 달리 '건강'이라는 키워드 자체가 광고·마케팅 수단으로 오염되어 있어, 건강식 카테고리에서는 정보 신뢰 문제가 더 교묘하고 심각하게 나타남. 또한 영양 정보 부재라는 별도 Pain이 추가 식별됨 — 건강 관리형 세그먼트 맞춤 해결과제.

**2. 재택근무 세그먼트에서 문제 1, 3이 동시에 최고 강도로 나타남**

박성민은 문제 1과 3 모두 5/5 점수를 부여했다. '별점 1개 부여 후 동일 식당 재추천' 경험은 피드백 루프 단절의 가장 직접적 증거. 재택 환경에서는 외출 결정 비용까지 더해져 탐색 포기-익숙한 선택 회귀 패턴이 오피스보다 더 빠르게 작동함.

**3. 장기 근무 단골형 세그먼트는 MVP 핵심 타깃에서 제외**

윤재호는 세 문제 모두 낮은 Pain을 보였다. 14년의 경험이 앱을 대체하는 개인 데이터베이스로 작동하고 있어 외부 도구의 필요성을 느끼지 못함. 단, 팀 신규 구성원 취향 파악 보조, 신규 오픈 식당 알림 등 부분적 니즈는 확인. 1차 MVP 타깃에서는 제외하되 2차 기능 설계 시 참고.

**4. 피드백 간소화와 즉각 반영 확인이 피드백 루프의 핵심 조건**

박성민이 제안한 "'또 먹고 싶어요 / 아니요' 수준의 초간단 피드백 + 즉시 추천 반영 확인"은 1~6번 인터뷰를 통틀어 가장 구체적인 솔루션 힌트. 피드백의 장벽(형식 복잡성) 제거와 보상(즉각 반영 가시화)을 동시에 설계해야 행동 동기가 형성됨.

**5. 문제 2의 근본원인 표현은 세그먼트별 온도차 존재**

박성민은 "광고 혼재보다 개인화 부재가 더 핵심"이라는 관점을 제시했다. 문제 2의 핵심 근본원인(광고 기반 구조)에 대해 세그먼트마다 공감 방식이 다름. 커뮤니케이션 설계 시 '광고 없는 추천'보다 '나를 아는 추천'으로 전면에 내세우는 방향이 더 폭넓게 수용될 가능성 있음.
