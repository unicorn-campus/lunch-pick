### 고객 관점 문제 (인터뷰 대상자가 인식하는 문제)

손지훈은 문제 1·2를 명확히 인식하고 있으나, 그 원인을 **자신의 귀찮음**으로 귀속하는 경향이 있었다. 플랫폼 구조 문제라는 시각은 질문을 통해 유도된 후에야 "아, 그렇게 볼 수도 있겠네요"로 동의하는 수준이었다. UX 전문가 배경 덕분에 광고 UI 문제에는 본인 직업적 감각으로 강한 공감을 표했다.

**대상자가 직접 언급한 불만 우선순위**:
1. 탐색 결과가 현재 내 위치, 현재 운영 여부, 현재 대기 상황을 반영하지 않음
2. 광고와 진짜 추천의 구분 불가
3. 피드백 루프 부재 (단, 본인 동기 문제로 인식)

---

### 개선 제안

- "인스타그램에서 발견 → 카카오맵에서 위치 확인 → 전화해서 영업 확인"을 한 번에 해주는 서비스가 있으면 무조건 쓸 것 같아요.

**근본원인 동의 여부**: 부정 — 문제로 인식하지 않음

> "솔직히 이건 저한테 크게 와닿지 않아요. 평가 안 하는 게 당연한 거 아닌가요? 다음 추천에 반영된다고 해도... 매번 먹고 싶은 게 달라지거든요. 오늘 기분, 날씨, 상황에 따라 완전히 달라지는데 '취향을 학습한다'는 게 얼마나 실제로 도움이 될지 모르겠어요. 오히려 '당신은 이런 거 좋아하잖아요'라고 AI가 고집 부리면 거슬릴 것 같아요."

**주요 발언**:
- "기록 자체를 안 하는 이유가 '반영이 안 돼서'가 아니라 그냥 안 하고 싶어서예요."
- "취향 학습이 완벽해도 컨텍스트가 안 맞으면 소용없어요. 오늘 술 마신 다음 날은 해장이 최우선인데, AI가 그걸 알까요?"
- "차라리 '오늘 몸 상태가 어때요?'처럼 실시간 컨텍스트를 물어보는 게 더 나을 것 같아요."

---

### 고객 관점 문제 (인터뷰 대상자가 인식하는 문제)

임도현은 **문제 1, 2에는 명확히 공감**하나 문제 3에는 의문을 제기했다. 재택 근무자 특유의 고립감으로 '탐색' 자체가 오락이기도 해서 문제 의식이 순수한 외식 직장인과 미묘하게 다르다. 취향 학습보다 **실시간 컨텍스트 반영**을 더 중요한 니즈로 제시하며, 문제 3의 프레임을 '기록 기반 학습'이 아닌 '상황 인식 추천'으로 재정의했다.

**대상자가 직접 언급한 불만 우선순위**:
1. 배달앱·외식 모두에서 발생하는 선택지 과부하 → 탐색-결정 단절
2. 광고 기반 정보 오염으로 신뢰 가능한 추천 채널 부재
3. 취향 학습보다 실시간 상황(날씨, 컨디션, 전날 식사)을 반영하는 추천

---

### 개선 제안

- "배달과 외식을 통합해서 '오늘 이 상황에선 이게 최선이에요'라고 딱 말해줬으면 해요. 배달이냐 외식이냐도 AI가 추천해주면 좋겠어요."
- "선택지를 3개로 줄여줘요. 최대 5개. 그 이상은 의미 없어요."
- "이유를 알고 싶어요. '이걸 추천하는 이유가 어제 한식 먹었고, 지금 날씨가 흐려서 따뜻한 국물이 어울려서' 이런 식으로요. 그게 있으면 신뢰가 생겨요."
- "취향 누적보다 오늘 상태 입력이 더 중요해요. '오늘 몸 상태, 시간 여유, 예산' 이 세 가지만 입력하면 바로 추천해주는 게 더 쓸 것 같아요."

### 세그먼트별 핵심 발견

**손지훈 (초기 경력 직장인 / 트렌드 민감층)**
- 탐색-결정 단절을 인지하나 원인을 자신의 귀찮음으로 귀속함. 구조적 문제로의 재프레이밍 필요
- 광고 문제에는 UX 감각으로 가장 민감하게 반응
- 피드백 루프는 "동기 부재"가 핵심 — 보상이 명확하면 행동 변화 가능성 있음

**황미영 (장기 근무 중간관리자 / 팀 식사 책임자)**
- 문제 1의 주요 대상이 아님 (탐색 포화로 탐색 자체를 포기한 단계)
- 문제 2, 3에 가장 강한 공감 — 특히 팀원 취향 데이터 관리를 최고 Pain Point로 제시
- AI 추천 신뢰 의심 — 비즈니스 모델 투명성에 대한 구체적 질문 제기

**임도현 (재택 기반 프리랜서 / 배달+외식 혼용)**
- 탐색이 오락 기능도 겸해서 문제 의식이 외식 직장인과 다름
- 문제 3을 가장 강하게 부정 — '취향 학습'보다 '실시간 컨텍스트'를 대안으로 제시함
- 배달-외식 통합 추천 니즈 — 기존 인터뷰 1~12번에서 발견되지 않은 새로운 니즈

### 신규 발견 인사이트

**인사이트 A: 문제 귀속 방식의 차이**
- 13번 손지훈, 15번 임도현 모두 구조적 문제를 초기에는 "나의 귀찮음" 또는 "나의 우유부단함"으로 귀속함
- 이는 문제 2의 "아는 사람 추천" 의존과 연결 — 플랫폼 불신이 자기 귀속으로 왜곡되는 패턴
- 서비스 포지셔닝 시 "당신이 귀찮은 게 아니라 도구가 나쁜 겁니다" 메시지 필요할 수 있음

**인사이트 B: 문제 3에 대한 세대/상황별 반응 편차**
- 팀 식사 책임자(14번)는 문제 3의 최고 지지자 — 피드백 루프 없이는 팀 관리가 불가능
- 재택 프리랜서(15번)는 문제 3에 부정 — 취향 고정보다 상황 유동성을 더 중요시
- 시사점: 문제 3의 솔루션은 "취향 누적"과 "실시간 컨텍스트" 두 축을 모두 지원해야 함

**인사이트 C: AI 신뢰 조건**
- 3명 모두 AI 추천의 잠재 가치는 인정하나, 신뢰 조건을 명확히 요구함
- 공통 신뢰 조건: 1) 광고 없음 증명, 2) 추천 이유 투명성, 3) 지속 운영 가능성(비즈니스 모델)
- 14번 황미영: "AI도 결국 어딘가서 수익을 내야 하잖아요. 그게 어떻게 될지 걱정" — 수익모델 투명성 신호 필요
