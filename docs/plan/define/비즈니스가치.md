# 비즈니스 가치

**서비스**: 런치픽(LunchPick) — 직장인을 위한 AI 기반 점심 메뉴 추천 서비스
**작성자**: 김성한 (피오) / 제품 책임자
**작성일**: 2026-02-26
**데이터 출처**: 문제가설.md (피봇 후), 문제검증인터뷰결과취합.md, 5명 에이전트 발산-수렴 결과

## 선정 과정

### 발산 참여자

| 역할 | 닉네임 | 프로파일 |
|------|--------|---------|
| 제품 책임자 (PO) | 피오 | 비즈니스 가치 중심, WHY 우선 |
| 서비스 기획자 (SP) | 도그냥 | 사용자 중심 사고, 시각적 스토리텔링 |
| 소프트웨어 아키텍트 (AR) | 아키 | 전체 그림, 트레이드오프 기반 판단 |
| AI 엔지니어 (AI) | 마법사 | 실용주의, 실제 문제 해결 AI |
| 도메인 전문가 (DE) | 인사이트 | 현장 경험 기반, 실무 검증 지식 |

### 수렴 결과 요약

발산 단계에서 5명의 에이전트가 각자의 관점에서 고객 가치와 회사 가치를 제안했다. 수렴 과정에서 유사한 항목을 통합하여 고객 측면 4개 후보, 회사 측면 5개 후보로 압축했다.

**최종 선정 기준**: 동의 수 + MVP 단계 검증 가능성 + 인터뷰 데이터 근거 강도

**고객 측면 후보 및 선정 결과**

| 순번 | 통합 가치명 | 동의 수 | 선정 |
|------|-----------|--------|------|
| 1 | 매일 낭비되는 점심 결정 시간의 회복 | 5/5 | 선정 |
| 2 | 쓸수록 나를 더 잘 아는 개인화 경험 | 5/5 | 선정 |
| 3 | 아는 사람 추천 수준의 신뢰감 | 4/5 | 선정 |
| 4 | 식사 선택의 후회 감소와 만족감 상승 | 2/5 | 제외 — 측정 지표가 가치 1·2와 중복되며 독립 가치 명제로서 검증 가능성 낮음 |

**회사 측면 후보 및 선정 결과**

| 순번 | 통합 가치명 | 동의 수 | 선정 |
|------|-----------|--------|------|
| 1 | 일일 반복 행위 기반의 압도적 리텐션 자산 | 3/5 | 제외 — 회사 가치 3(데이터 Lock-in)과 내용 중복, 독립 검증 지표 도출 어려움 |
| 2 | 광고 없는 구독 수익 모델의 시장 검증 | 5/5 | 선정 |
| 3 | 사용할수록 강해지는 데이터 기반 Lock-in | 4/5 | 선정 |
| 4 | 팀 모드 확장을 통한 B2B 수익화 경로 | 3/5 | 선정 — 동의 수는 중간이나 인터뷰에서 3명(권태성·황소연·황미영)이 독립적으로 팀 니즈를 제기했고, MVP 이후 2단계 수익화 경로로서 MVP 단계부터 설계에 반영 필요 |
| 5 | Explainable AI가 만드는 차별화 포지션 | 2/5 | 제외 — 동의 수 낮고 고객 가치 3(아는 사람 추천 신뢰감)의 기술 구현 방법으로 통합 |

## 고객 측면의 비즈니스 가치

### 가치 1: 매일 낭비되는 점심 결정 시간의 회복

- **정의**: 직장인이 매일 점심 메뉴를 고르는 데 평균 13~18분을 탐색하지만 결국 기존 단골로 회귀하는 "기억 없는 반복 탐색" 사이클을 끊어내고, 결정에 쓰는 시간을 5분 이내로 단축한다. 탐색이 아닌 결정을 제공하는 것이 런치픽의 출발점이다.
- **검증 근거**:
  - 핵심 타깃 8명 기준 문제 1 중요도 4.50/5.0, 불편도 4.38/5.0으로 세 문제 중 최고 Pain 강도 기록
  - "매일 카카오맵 켜고 검색하는데, 결국 작년이랑 똑같은 데 가고 있어요. 시간만 쓰는 거죠." — 민준혁 (핀테크 개발자, 31세)
  - "탐색 자체를 안 하게 됐어요. 6년 다니면서 쌓인 맛집 정보가 팀 바뀌고 나서 다 사라졌거든요." — 오채연 (금융 마케터, 38세)
  - 인터뷰에서 "3~5개로 제한된 추천"을 요청한 응답자 6명 — 탐색 제거가 핵심 UX 설계 방향 확인
- **측정 지표**:
  - 앱 진입 후 메뉴 결정까지 소요 시간 (목표: 5분 이내, 현재 평균 13~18분 대비 60% 이상 단축)
  - 일간 활성 사용자(DAU) 추천 수용률 (추천 결과로 실제 식당 방문/주문 전환율)
  - 앱 내 탐색 없이 추천 결과 수락 비율 (0회 재탐색 비율)

### 가치 2: 쓸수록 나를 더 잘 아는 개인화 경험

- **정의**: 사용자가 런치픽을 사용할수록 과거 식사 취향이 누적되고 오늘의 컨텍스트(날씨, 컨디션, 전날 메뉴)까지 반영되어 추천 품질이 점진적으로 향상되는 경험을 제공한다. "쓸수록 나아지는 서비스"라는 체감이 핵심이며, 이는 단순 메뉴 나열과 구분되는 런치픽의 본질적 차별점이다.
- **검증 근거**:
  - 문제 3(피드백 루프 단절) 중요도 3.87/5.0으로 세 문제 중 최고, 강하게 동의 47%(7명)로 세 문제 중 최고
  - "별점 남겨봤자 내 추천이 달라진 적이 없어요. 그냥 남들한테 주는 리뷰잖아요, 나한테 돌아오는 게 없는." — 정수아 (스타트업 마케터, 31세)
  - "어제 닭볶음탕 먹었으면 오늘은 국물 빠진 거 추천해줬으면 하는데, 그런 기능은 어디도 없더라고요." — 박성민 (콘텐츠 마케터, 34세)
  - 초간단 피드백(이모지·3택 등) 요청 7명, 즉각 반영 확인 요청 6명 — 피드백 UX 방향 구체적으로 검증
  - 임도현(15번): 취향 학습뿐 아니라 "오늘 컨텍스트 반영"의 중요성 제기 — 이중 인풋 구조 설계 근거
- **측정 지표**:
  - 사용 주차별 추천 만족도 변화 추이 (1주차 vs 4주차 vs 8주차 비교)
  - 사용자당 누적 피드백 횟수 (목표: 월 20회 이상)
  - 재방문율 및 30일 리텐션 (목표: 30일 리텐션 40% 이상)

### 가치 3: 아는 사람 추천 수준의 신뢰감

- **정의**: 사용자가 추천 결과를 받을 때 "왜 이 메뉴인가"를 명확히 이해할 수 있도록 추천 이유를 투명하게 제공함으로써, 광고나 협찬이 없는 "아는 사람이 나 상황 알고 추천해주는" 수준의 신뢰를 형성한다. 신뢰는 런치픽이 기존 플랫폼과 구분되는 가장 중요한 포지션이다.
- **검증 근거**:
  - 15명 전원이 인터뷰 과정에서 자발적으로 "아는 사람 추천"을 신뢰의 준거점으로 언급 — 전원 일치
  - 추천 이유 설명을 직접 요청한 인터뷰이 7명: 민준혁, 정수아, 박재현, 손지훈, 황미영, 임도현, 박지안
  - "광고인지 아닌지 모르겠는 게 더 무섭죠. 차라리 광고라고 표시해주면 걸러쓸텐데." — 손지훈 (스타트업 UX 디자이너, 28세)
  - 박지안(미식형, 28세): "협찬 없는 취향 기반 추천"을 원하며 유료 지불 의사까지 표명
  - 황미영·임도현: 독립적으로 "광고 없는 AI 추천을 믿지만, 수익 구조도 투명해야 한다"고 언급 — 비즈니스 모델 투명성이 신뢰의 전제 조건
- **측정 지표**:
  - 추천 신뢰도 평가 점수 (목표: 4.0/5.0 이상)
  - "이 추천을 친구에게 공유하고 싶다" 응답 비율 (NPS 연계)
  - 추천 이유 화면 열람율 (Explainability 기능 사용률)

## 회사 측면의 비즈니스 가치

### 가치 1: 광고 없는 구독 수익 모델의 시장 검증

- **정의**: 식당 정보 서비스 시장에서 광고 수익 모델이 아닌 "개인화 추천 품질에 대한 사용자의 직접 지불(구독료)" 모델이 성립하는지를 MVP 단계에서 검증한다. 이 검증이 성공하면 광고 없이 사용자 가치에 정직하게 정렬된 foodtech 수익 모델의 선례를 만든다.
- **검증 근거**:
  - 5/5 만장일치 동의 — 5명 에이전트 전원이 런치픽의 핵심 비즈니스 가설로 인정
  - 황미영·임도현: "광고 없는 AI 추천을 믿겠지만, 그 AI도 수익을 내야 하는데 결국 광고로 가는 건 아닐까"라고 의구심 제기 — 구독 모델 선언이 신뢰 형성의 필수 조건임을 확인
  - 박지안(28세): 신뢰 기반 추천에 유료 지불 의사 표명 — 지불 의향 있는 세그먼트 실존 확인
  - 문제가설 5WHY: "개인화 추천 품질을 사용자가 직접 지불할 의향이 있다는 것이 시장에서 입증된 사례 없음"이 기존 플랫폼들의 구독 모델 미진입 이유 — 이 공백을 런치픽이 최초 검증
- **측정 지표**:
  - 구독 전환율 (무료 체험 → 유료 구독 전환, 목표: 10% 이상)
  - 월간 구독 유지율 (Monthly Churn Rate, 목표: 월 10% 이하)
  - 구독 의향 설문 응답율 (베타 단계, 목표: 30% 이상)

### 가치 2: 사용할수록 강해지는 데이터 기반 Lock-in

- **정의**: 사용자가 런치픽을 쓸수록 개인 식사 이력·취향·피드백 데이터가 누적되어 추천 품질이 향상되는 플라이휠 구조를 형성한다. 이 데이터는 경쟁사가 단기간에 복제할 수 없는 개인화 데이터 해자(Data Moat)가 되며, 사용자 입장에서도 축적된 취향 데이터를 포기하는 전환 비용이 커져 자연스러운 Lock-in이 발생한다.
- **검증 근거**:
  - 배달의민족·요기요는 주문 플랫폼, 망고플레이트·식신은 리뷰 플랫폼으로 "결정 지원 + 개인 취향 학습" 특화 경쟁자 없음 — MVP정의.md 경쟁 분석
  - 문제가설 5WHY: "기존 플랫폼은 광고 수익 최적화를 위한 통계 기반 추천을 사용하며 개인별 취향 학습 엔진을 구현하지 않았다" — 시장 공백 확인
  - 핵심 타깃 8명 전원이 "피드백이 내 추천에 반영되면 더 쓰겠다"는 방향 동의 — 취향 데이터 축적의 이탈 방지 효과 확인
  - 오채연: "6년 다니면서 쌓인 맛집 정보가 팀 바뀌고 나서 다 사라졌다" — 데이터 소실에 대한 상실감이 Lock-in의 반증
- **측정 지표**:
  - 사용자당 누적 식사 이력 건수 (90일 기준, 목표: 50건 이상)
  - 취향 프로파일 완성도 지수 (추천 알고리즘이 사용할 수 있는 데이터 충분성)
  - 60일 이상 사용자의 이탈율 (취향 데이터 축적 이후 이탈율 감소 확인)

### 가치 3: 팀 모드 확장을 통한 B2B 수익화 경로

- **정의**: MVP에서는 개인 추천에 집중하되, 팀 식사 책임자(팀장, HR 담당자)가 팀원 취향 데이터를 관리하고 팀 점심 의사결정을 지원하는 팀 모드를 2단계로 확장함으로써 B2B 구독 수익화 경로를 확보한다. 팀 모드는 개인 모드 대비 단가를 높일 수 있고, 조직 단위 계약으로 안정적 ARR을 형성할 수 있다.
- **검증 근거**:
  - 인터뷰 15명 중 3명(권태성, 황소연, 황미영)이 독립적으로 팀 취향 데이터 관리 니즈를 제기 — 동일 Pain을 다른 직군에서 반복 확인
  - 황소연(HR 팀장, 42세): "8년 동안 팀 점심 메뉴 담당인데, 엑셀로 직접 관리한다" — 대안 없는 Pain의 현재 상태 확인
  - 권태성(인프라팀장, 35세): "4년간 팀 점심 담당, 팀원 알러지·선호도 일일이 기억한다" — 구조적 해결 요구
  - 인사이트 5: "팀 취향 데이터 관리라는 Pain은 개인 추천보다 오히려 더 구체적이고 명확한 비어있는 시장" — 문제검증인터뷰결과취합.md
- **측정 지표**:
  - 팀 모드 대기자 등록 수 (MVP 단계 사전 수요 측정)
  - 팀 모드 베타 참여 팀 수 및 팀당 평균 구성원 수
  - 팀 모드 전환 의향 설문 응답율 (개인 사용자 중 팀 기능 도입 의향, 목표: 20% 이상)

## 가치 간 관계

고객 가치와 회사 가치는 분리된 목표가 아니라 하나의 플라이휠 구조로 연결된다.

```
[고객 가치 1: 결정 시간 회복]
  → 빠른 추천 수락 → 앱 일일 사용 습관 형성
          ↓
[고객 가치 2: 쓸수록 나아지는 개인화]
  → 피드백 제공 → 취향 데이터 누적
          ↓
[회사 가치 2: 데이터 기반 Lock-in]
  → 전환 비용 상승 → 이탈 방지 → 장기 리텐션
          ↓
[고객 가치 3: 아는 사람 추천 신뢰감]
  → 추천 품질 향상 + 이유 투명성 → 신뢰 형성
          ↓
[회사 가치 1: 구독 수익 모델 검증]
  → 신뢰가 지불 의향으로 전환 → 광고 없는 수익 확보
          ↓
[회사 가치 3: 팀 모드 B2B 확장]
  → 개인 Lock-in 사용자 중 팀장·HR 담당자 → 팀 구독 전환 → ARR 형성
```

**관계 핵심 인사이트**:
- 고객 가치 1(결정 시간 회복)은 진입점이다. 사용자를 앱으로 끌어오는 최초 동기다.
- 고객 가치 2(쓸수록 나아지는 개인화)와 회사 가치 2(데이터 Lock-in)는 동전의 양면이다. 사용자에게는 더 나은 추천으로, 회사에게는 전환 비용 상승으로 동시에 작동한다.
- 고객 가치 3(신뢰감)은 회사 가치 1(구독 수익 검증)의 전제 조건이다. 신뢰 없이 구독료 지불은 발생하지 않는다.
- 회사 가치 3(팀 모드 B2B)은 개인 Lock-in이 충분히 형성된 이후 자연스럽게 발생하는 2단계 수익화다.

## MVP 단계 핵심 가치 선언

런치픽은 매일 반복되는 점심 결정 피로를 끊어내기 위해 직장인의 식사 이력과 오늘의 컨텍스트를 학습하여 이유 있는 추천 3~5개를 5분 안에 제공하고, 쓸수록 나를 더 잘 아는 개인화 경험을 통해 "아는 사람의 추천"처럼 신뢰받는 유일한 점심 결정 파트너가 된다.
